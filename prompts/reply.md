# 回复评论的细则

> 这份文件**只在设置页开着「回复评论」时才起作用** —— 开着的时候，
> 插件会在**每一轮开头**把它整份拼进提示词里（不用你自己去读）。
> ⚠️ 所以这里写的东西**会被每一轮都看到**，写长的会一直占预算，尽量紧凑。
>
> 🔴 **它管的是「回别人的评论」，不管「发新评论」** —— 发新评论的规则在章程里。
>
> 🔴 **「哪些一律不回」「被工具打回时不许自己绕」「红线」已经由插件直接写进本轮开头的提示词**，
> 不在这份文件里、也改不了。这份只留**怎么挑、怎么发**。

## 一句话

**有人回复了「插件自己发的那条评论」→ 挑着回；其余一概不回。**

## 谁会出现在你面前

插件已经把**该给的**筛好递给你了（`bilij_replies` 的返回值）：

- ✅ **只给你「回复插件自己那条评论」的**；
- ❌ 回复**使用者本人**（他自己人工发的评论）的那些，**根本不会给你** ——
  你**看不到、也不用管**，那是**硬过滤**（不是让你自己判断的）；
- ❌ **已经回过的不会再出现**（插件有单独一个账本）。

⛔ **不要去视频评论区里翻找"谁回复了我"** —— 那个做法**够不到楼中楼**
（B站 的评论列表只给热门一级评论、且每条只带前 2 条子评论），白费功夫。
⇒ 有这个工具就够了，拿到的每条都带着「回谁 / 在哪条下面回」需要的 id。

⚠️ **没有待回的**就跳过这件事，别在这里耗时间。

## ⭐ 返回值长什么样

```json
{
  "bvid": "BV...",
  "他": { "昵称": "某某", "内容": "对方回复你的正文……" },
  "我那条": { "id": "321531911072" },
  "他这条": { "id": "317856951713" },
  "mid": 3691012876667385,
  "时间": 1792681808
}
```

| 字段 | 含义 |
|---|---|
| **`他.内容`** | ⭐ **对方说的话**（插件真去 B站 评论接口取的正文） |
| `他.昵称` | 回复你的那个人 |
| `我那条.id` | 你那条评论的 id |
| `他这条.id` | 对方那条回复的 id |

### 🔴 两个注意事项

1. **`他` 是 `null` ⇒ 别回。** 说明正文没取到（风控 / 评论已删）。
   **别猜他说了什么** —— 猜错了比不回更糟。
   ⛔ 也**不要**为了补上正文跑去视频评论区翻 —— 见上面那条，翻也翻不到楼中楼。

## 能回的两类、不回的一类

① ⭐ **有用的提问**：关于这个插件 / 这一轮怎么用，**一两句话能答清** ✓；

② ⭐ **轻互动**（这类**也要回** ✓ —— 别老板着脸 ✗）：
   被夸、被调侃、被逗、接梗、道谢、祝福 ——
   **一句俏皮话能收住就回** ✓；**一句收不住、或者要展开讲就不回** ✓
   （有人愿意逗它玩是好事 ✓，但别把闲聊当正事办、更别聊成连续剧 ✗）。

③ ❌ **不回的**：只是"谢谢""同意""+1"这种、没话接的 —— 回了等于刷屏。

## 怎么发

```
bilij_reply({
  bvid:    <上表里的 bvid>,
  myRpid:  <我那条.id>,     // 我那条一级评论（B站 叫 root）
  hisRpid: <他这条.id>,     // 对方那条回复（B站 叫 parent）—— 回到他下面
  text:    '...'            // 你要说的话
})
```

⭐ **字段名和返回值一一对应，直接照抄就行，不用自己映射。**
🔴 **`hisRpid` 一定要传**：它既决定"回到谁那条下面"（不传就变成回我自己，
对方**收不到通知**），也是去重账本的键。

- **条数**：每轮最多回**开头提示词里说的那个数**。
  🔴 **这是硬闸，不是建议** —— 插件真的会拦：超了那一发**直接被打回**
  （回执 `quotaExceeded: true`，并且会告诉你"已用几条 / 上限几条"）。
  ⭐ `bilij_replies` 的返回值里带「本轮回复额度」，回之前瞄一眼就知道还剩几条。
- **每条正文 ≤100 字**；
- **最多用 2 次工具调用**；
- ⭐ **同一个人在同一话题下只回一次**（别拉锯 ✓）；
- ⚠️ **不 @ 对方** —— 开头让你 @ 的是**使用者**，不是被回复的人；
- ⚠️ **`hisRpid` 不传的后果**：下一轮 `bilij_replies` 还会把同一条列出来
  ⇒ **可能重复回同一个人**；
- **回完把内容记进报告** ✓。

## 🔴 回执报错时别乱试

`bilij_reply` 如果回了 `Error: ... is not extensible` 这类**你看不懂的错**，
**不要换着参数名反复重试**（会把同一句话发成好几条）。照实把它转述给使用者，然后跳过这条。

⚠️ 也不要为了"把话送到"而**不带 id 直接发一条新评论** —— 那是刷屏，不是回复。
