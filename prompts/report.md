# 报告书写规范（写笔记）

> 这一份管「**挑中的视频，笔记怎么写**」。
> 🔴 **只在「怎么写 = 写笔记」时才用得上**（设成「不写」时本轮不生成任何文件）。
> 它由使用者维护（面板「提示词」页的「报告书写规范」），可以改。
>
> ⚠️ **不是**这份说了算的：写在哪、文件名长什么样 —— 那些由**开头提示词**给（每轮都不同）。

## 一、一份一份写，不写汇总

- ⭐ **挑中的每一条，各写一份独立的 Markdown 文件**。
- ⛔ **不要写汇总日报**（「今天推荐了 N 条」那种）。一份文件只讲一条视频。

## 二、这是一篇「视频笔记」，不是一句推荐语

目标是：**使用者没看视频，只读这份笔记就能把重点搞明白**。

结构照这个来：

```markdown
# <视频标题>
> 一两句说清「这条在讲什么」
- **UP** / **链接** / **播放量** / **时长**
## 讲了什么      ← 主体：把核心内容讲清楚
## 关键点        ← 3~6 条（方法 / 数字 / 结论 / 反直觉之处）
## 为什么值得看   ← 两三句（给谁看、能拿走什么）
## 我的一句话    ← 你自己的判断（可以尖刻，按人设来）
```

## 三、内容要求（这几条最容易做不到）

- ⭐ **「讲了什么」要落到细节**：具体的方法名 / 做法 / 关键数字 / 对比基线 / 结论的边界。
  **照字幕原文写**，别只写标题级的概括；这是笔记，**宁可长一点**。
- ⚠️ **只写视频里真有的**：字幕没讲的**别补、别脑补、别拿你已有的知识去填**；
  拿不准就写「视频里没细说」。
- ⚠️ **评论仍要简洁**（见「评论」那段）—— **别把笔记内容抄进评论**：
  笔记是给人细读的，评论只是叫他来看一眼。

## 四、保底：这一轮无论发生什么，都要留下痕迹

- ⭐ **至少留一行**：哪怕只写「本轮失败：原因是 X，下次重试」 ✓
  （除非开头明确说「不写」）。
- ⭐ **判重表里也至少留一行** ✓（判重表任何一档都要写 —— 它是「看过什么」的账）。
- **理由**：产物目录是空的、判重表不存在 ⇒ 使用者**完全看不到这一轮发生了什么**，
  也**不知道这一轮白烧了钱**。
- ⇒ 顺序上：**先把这两样落下，再去做别的**（万一后面卡住，至少账是清楚的）。

## 五、磁盘上顺带记一笔

- 产物里顺带一行：**`因无字幕跳过 N 条`**（N=0 也写）——
  让人一眼知道这轮有没有漏。
- 跑过的每一条都会进判重表（看过 / 挑中 / 评论三种来路），日志留在插件数据目录。
